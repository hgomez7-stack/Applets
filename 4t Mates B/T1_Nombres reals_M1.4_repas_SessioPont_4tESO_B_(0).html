Conjunts de nombres Repàs
Sessió pont

N ⊂ Z ⊂ Q ⊂ R, i els irracionals a part

Cada conjunt «engloba» l'anterior. Els irracionals són reals que no es poden escriure com a fracció — mai toquen els racionals.

Idea clau: tot nombre real és racional o irracional — mai les dues coses alhora. R = Q ∪ I.

La recta real Repàs
Sessió pont

Cada nombre real té el seu lloc exacte

Enters, racionals i irracionals conviuen tots a la mateixa recta — sense buits.

Per ordenar-los a la recta: si cal, passa'ls tots a forma decimal (les fraccions es divideixen, els irracionals s'aproximen) i compara.

Control de l'error · Resum Repàs
Sessió pont
±

Quan aproximem, sempre hi ha un error

Tres idees clau, ja treballades a la sessió anterior: quant val l'error, quant «pesa» i com arrodonim.

Error absolut
Eₐ = |valor real − aproximat|
Mateixes unitats que la mesura.
Error relatiu
Eᵣ = Eₐ ÷ |valor real|
Sense unitats; compara errors entre mesures diferents.
Arrodoniment
Mira la xifra següent: si és ≥5, puja la darrera; si és <5, la deixa igual.
Trencament (truncament)
Simplement «talles» les xifres sobrants, sense mirar la següent ni arrodonir.

[a,b]

Un tros de la recta real, escrit de moltes maneres

La mateixa idea es pot expressar amb claudàtors, amb una desigualtat o descrivint el conjunt.

NomNotació intervalDesigualtatRecta
Tancat[a, b]a ≤ x ≤ b●━━━●
Obert(a, b)a < x < b○━━━○
Semiobert (dreta)[a, b)a ≤ x < b●━━━○
Semiobert (esquerra)(a, b]a < x ≤ b○━━━●
Semirecta dreta(−∞, a]x ≤ a←━━━●
Semirecta esquerra[a, +∞)x ≥ a●━━━→
Claudàtor tancat [ ] = inclou l'extrem (cercle ple). Parèntesi obert ( ) = no l'inclou (cercle buit).
Apunt: un entorn de centre a i radi r és l'interval obert E(a,r) = (a−r, a+r). Exemple: E(3, 0,5) = (2,5, 3,5).

Sessió pont
aⁿ

Set propietats, d'un cop d'ull

Tot el que vam veure a la Sessió 4, en una sola taula.

PropietatFórmulaExemple
Producte, mateixa baseaᵐ × aⁿ = aᵐ⁺ⁿ2³×2⁴=2⁷
Quocient, mateixa baseaᵐ ÷ aⁿ = aᵐ⁻ⁿ5⁶÷5²=5⁴
Potència d'una potència(aᵐ)ⁿ = aᵐ·ⁿ(3²)⁴=3⁸
Potència d'un producte(a·b)ⁿ = aⁿ·bⁿ(2·5)³=1000
Potència d'un quocient(a÷b)ⁿ = aⁿ÷bⁿ(10÷2)³=125
Exponent negatiua⁻ⁿ = 1 ÷ aⁿ2⁻³=0,125
Exponent zeroa⁰ = 17⁰=1
Recorda: per sumar/restar exponents, les bases han de ser iguals.
